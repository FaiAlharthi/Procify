# Example RFP: Downtown Public Wi-Fi Network Installation

**Issuing Organization:** City of Eastport
**RFP Reference:** COE26-25

## 1. Objective
The City of Eastport seeks a vendor to design, install, and maintain a free public Wi-Fi network covering its downtown core and main public square, supporting both resident access and local business district revitalization goals.

## 2. Scope of Work
- Network design covering approximately 1.5 square kilometers of downtown core
- Supply and installation of outdoor wireless access points and supporting infrastructure
- Network management portal for usage monitoring and content filtering
- Ongoing network maintenance and technical support

## 3. Technical Criteria
- Network must support a minimum guaranteed bandwidth per concurrent user during peak usage
- System must include appropriate content filtering in compliance with municipal public access policies
- Infrastructure must be weatherproofed and rated for outdoor year-round operation
- Vendor must provide network uptime guarantees with defined remediation timelines

## 4. Commercial Template
Proposals must include installation costs separate from ongoing annual maintenance and bandwidth costs, with any optional advertising/sponsorship revenue-sharing models described if applicable.

## 5. Project Delivery & Deadlines
Installation must be completed within 5 months of contract award, with network testing and public launch coordinated ahead of the City's summer downtown events season.
