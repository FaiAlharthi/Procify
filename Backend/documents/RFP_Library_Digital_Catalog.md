# Example RFP: Public Library Digital Catalog & Lending System

**Issuing Organization:** Westfield Public Library Network
**RFP Reference:** WPLN26-06

## 1. Objective
Westfield Public Library Network seeks a vendor to supply a modern digital catalog and e-book/audiobook lending platform to replace its current legacy system across 9 branch locations, improving patron access to digital and physical collections.

## 2. Scope of Work
- Unified digital catalog searchable across all physical and digital holdings
- Integrated e-book and audiobook lending platform compatible with major reading devices
- Patron account management, including holds, renewals, and fine tracking
- Migration of existing catalog data from the legacy system

## 3. Technical Criteria
- Platform must support standard library data exchange formats (e.g., MARC records)
- System must be accessible via web browser and dedicated mobile app
- Vendor must ensure patron data privacy in compliance with applicable regulations
- Platform must support single sign-on with existing library card authentication

## 4. Commercial Template
Proposals must include implementation/migration costs separate from ongoing annual licensing fees, with pricing scaled to the network's patron base size.

## 5. Project Delivery & Deadlines
Data migration and system testing must be completed within 4 months of contract award, with a phased branch-by-branch rollout over the following 2 months.
